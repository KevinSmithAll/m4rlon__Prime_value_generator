# Random Prime Number Generator
Этот проект представляет собой функцию для генерации случайных простых чисел. Простые числа играют важную роль в современной криптографии, особенно в алгоритмах шифрования с открытым ключом, таких как RSA.

## О простых числах
Простое число — это натуральное число больше единицы, которое делится только на единицу и само себя. Примеры простых чисел включают 2, 3, 5, 7, 11 и так далее. Простые числа имеют фундаментальное значение в математике и широко используются в различных областях, включая криптографию.

Применение простых чисел в криптографии
Простые числа являются основой многих современных криптографических алгоритмов. Вот несколько примеров их применения:

## Алгоритм RSA
RSA — один из наиболее известных и широко используемых алгоритмов асимметричного шифрования. Он основывается на сложности факторизации больших составных чисел, которые являются произведением двух больших простых чисел. Чем больше эти простые числа, тем сложнее взломать шифр.

## Протокол Диффи-Хеллмана
Протокол Диффи-Хеллмана используется для обмена ключами между двумя сторонами, обеспечивая безопасность передачи данных. Этот протокол также полагается на свойства простых чисел и сложность вычисления дискретных логарифмов.

## Эллиптические кривые
Алгоритмы на эллиптических кривых (ECC) используют простые числа для построения кривых, которые обеспечивают высокую степень безопасности при меньших размерах ключей по сравнению с RSA.

### Использование функции генератора простых чисел
Функция в данном проекте генерирует случайные простые числа заданной длины. Это полезно для тестирования и разработки криптографических приложений, где требуются большие простые числа.
