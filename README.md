# Prime_value_generator

В этом репозитории находится функция, которая является генератором простых чисел из заданного промежутка. Простые числа однозначно используются в современных алгоритмах симметричного и асимметричного шифрования, в алгоритме Дифф-Хеллмана, а также при создании цифровых подписей
